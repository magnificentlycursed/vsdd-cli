## Design Specification

### Summary

The meta-harness must **prove, from the run record, that its own disciplines fired for every dispatched agent** — the phase-appropriate primer, composed domains, and supplements were loaded; the intended tools were used; the run was right-sized (cache, model/effort, targeted reads). "Availability is not activation" (contract §133) is already ratified law; this subsystem **mechanizes** it, turning cargo-cult performance (personas that ship as files nobody loads) into verified conformance. **Verifiable conformance is the center of gravity; efficiency/right-sizing is one axis under it** (operator ruling 2026-07-31). This is a spec amendment: it supersedes `DESIGN-OBSERVABILITY.md`, re-scopes "Cost is knowable" (§140-153), and re-grounds the AI-Engineer domain from observability-lens to measured right-sizing/conformance judge; Red Team is re-pointed at control circumvention.

**Founding evidence (two live instances, not hypothetical):** (1) the #821 cold-review lenses read no `vsdd-domain-*` persona — they got their lens from the dispatch prompt, not the files (recorded in `wf_0ac03bda-2ee` transcripts). (2) *This cycle's own opening* bypassed the personas — the orchestrator dispatched a general-purpose subagent with a paraphrase of the composition until the operator caught it; the correct path (load the files) was not the only path, and the catch was **human, not mechanized.**

### Requirements

- **REQ-1 — Phase is recorded.** Every dispatched agent's run carries the phase it executes, sourced from the state artifact / crosslink session breadcrumb (§37), not self-asserted. *Grade:* recorded (verification-only). *Falsifier:* a dispatch whose record names no phase, or a phase disagreeing with the milestone state. *Bypass closed:* run "phaseless" and claim any discipline post-hoc.
- **REQ-2 — Phase primer loaded.** The phase primer for the recorded phase is present in the dispatched agent's context **by injection at dispatch** (primary), or where injection cannot reach, by a read-gate on the primer's recorded Read (§133); verified by a Read event for the primer in the transcript. *Grade:* injection-by-construction (capability) primary; read-gate (friction) fallback; CI-backed verification. *Falsifier:* a run whose transcript lacks the required primer Read/injection. *Bypass closed:* inline the primer's content in the prompt (no Read recorded); read-then-ignore (residual → cold review, per REQ-13).
- **REQ-3 — Composed domains loaded.** The domain personas the composition function requires for this phase/surface are present by injection; verified `Reads ⊇ composition-required domains`. *Grade/falsifier/bypass* as REQ-2. *Bypass closed:* load fewer/wrong domains; paraphrase them in the prompt (the #821 + this-cycle failure).
- **REQ-4 — Supplements loaded.** The language/interface supplements in scope (the claude-code-cli supplement for runtime-harness work; the language supplement for code) are present by injection; verified. *Bypass closed:* skip; wrong-language supplement.
- **REQ-5 — Intended tools used; no hand-rolled affordance.** A methodology act uses its mapped tool/affordance (act-to-affordance map §130); a Bash string re-implementing a mapped affordance is a flagged nonconformance. *Grade:* CI-backed detection. *Falsifier:* a hand-rolled equivalent of a mapped affordance with no stated reason (§130's own falsifier, now checked). *Bypass closed:* hand-roll the tool's job in shell to skip the tool and its checks — must also make the tool the path of least resistance (RT: correct path = only path).
- **REQ-6 — Cache leveraged; warm handoff.** Shared context is passed to a dispatched agent as a warm slice, not cold-reloaded per agent; verified by `cache_creation` analysis (cross-agent redundant fresh-load of the same context is flagged). *Grade:* by-construction in the dispatch primitive + detection. *Falsifier:* N cold agents each `cache_creating` the same base context. *Bypass closed:* cold-reload anyway (AIE sycophancy mode: "sub-agent re-loads context the parent already has"; "prompt-cache hit assumed across 5-minute TTL boundary").
- **REQ-7 — Model + effort specified.** Every dispatch records explicit model and effort dials; unspecified dials fail closed (§91 "never inherited"). *Grade:* friction/block at dispatch. *Falsifier:* a dispatch with defaulted/unrecorded dials. *Bypass closed:* silent inherit (AIE mode: "model-tier choice made by intuition not per-task cost-benefit").
- **REQ-8 — Reads offset/limit-scoped.** A `limit=none` Read of a large governed file is flagged; the warm slice (REQ-6) removes the reason to full-load. *Grade:* detection. *Falsifier:* full-doc load where a slice was available. *Bypass closed:* full-load with no penalty. (The #821 lens that read the contract in 1–4-line windows is the positive control.)
- **REQ-9 — Composition→verifier binding.** The composition function (Slice 2) computes the SHOULD (required primer/domains/supplements for the phase/surface); the verifier reads the WAS (the run record); conformance is `WAS ⊇ SHOULD`; the gate blocks the delta. *Grade:* CI-backed block. *Falsifier:* a conformant-marked run whose WAS is missing a SHOULD member. *Bypass closed:* declare a composition and dispatch a different (thinner) one.
- **REQ-10 — The oracle is unforgeable by the checked agent.** All conformance/efficiency evidence is drawn from harness-produced records (Claude Code transcripts, which the agent cannot author) verified by CI over server-synced state (§264/#815 tamper-evidence keystone) — never from agent-authored claims. *Grade:* independent-oracle (the only tamper-proof grade). *Falsifier:* a control resting on an agent-writable record. *Bypass closed:* the agent fabricates its own conformance evidence.
- **REQ-11 — Cost re-scoped to static price + records-based insight.** Retain the static price (Slice 2: the priced bill at build + CI bloat-gate) and answer the cost questions from the run records (per REQ-14). Retire the telemetry apparatus (OTel collector, dashboards, dollar ledger, calibration-tied-to-dollar-actuals) — under subscription auth, dollars are a projection; the binding constraints are usage windows and operator time (§144). *Grade:* spec-amendment (SO). *Falsifier:* a cost figure without capture-source provenance (§151, retained); a composition whose static price cannot be produced.
- **REQ-12 — Personas and supplements are controls, not prose.** Their enforceable content becomes conformance checks; their required content is delivered by injection (REQ-2/3/4); only irreducible judgment-shaped guidance remains as prose, and it is injected (not description-matched) and audited by the cold review that receives the same slice — the one instrument that catches read-but-ignored (§133). *Grade:* mixed (checks CI-backed; injection by-construction). *Falsifier:* a persona/supplement relied on solely as prose-to-be-read. *Bypass closed:* ship a discipline as a persona sentence and assume compliance (the founding failure).
- **REQ-13 — Review is independent-of-frame always; cold-vs-warm on artifacts is a right-sized dial.** Adversarial review is by a different agent, never given the author's reasoning (independence). Reviewers may be **warm on raw artifacts** (handed the raw diff/design/contract slice) but never on a curated summary (curation re-imports the author's blind spot). True cold (re-load raw yourself) is reserved for terminal rounds guarding collective anchoring. *Grade:* discipline mechanized as a dispatch-composition rule. *Falsifier:* a reviewer handed the author's rationale, or a curated summary in place of the raw artifact. *Bypass closed:* "cold" used to justify redundant re-load without adding independence (the cross-agent waste of REQ-6).
- **REQ-14 — Efficiency insight engine.** A reader over the run records surfaces the AI-Engineer dimensions with provenance on every figure (recorded / measured / judgment): capture-source provenance; cost-band cataloging per operation; prompt-cache discipline (5m vs 1h TTL utilization); sub-agent scope-down (warm vs cold); model-tier + effort right-sizing per task; cross-agent redundant-load. *Grade:* detection/advisory, surfaced through crosslink's existing viewers (§149 "vsdd builds no viewer"). *Falsifier:* an advisory figure without capture-source provenance; a calibration claim with no linked actual.
- **REQ-15 — The design process is itself conformance-checked and Red-Teamed** (operator ruling 2026-07-31). A design/review cycle's own dispatches are subject to REQ-1..10, and Red Team reviews both the process (was the correct path the only path, or was an easier bypass available and taken) and the artifact (are the controls circumventable). *Grade:* CI-backed (the cycle's own dispatch records are checked) + adversarial review. *Falsifier:* a cycle that declares a composition but whose dispatch records show the personas unloaded (this cycle's own opening — caught by the operator, which is itself the finding that the control must be mechanized, not human-caught).

### Acceptance Criteria

- [ ] AC-1: a dispatch record with no phase, or a phase ≠ milestone state, fails the check (REQ-1).
- [ ] AC-2: a dispatched agent whose transcript lacks the required primer Read/injection fails the conformance gate; a run with it passes (REQ-2).
- [ ] AC-3: a run whose loaded domains are a strict subset of the composition-required set fails; `Reads ⊇ required` passes (REQ-3, REQ-9).
- [ ] AC-4: a run missing an in-scope supplement fails; present passes (REQ-4).
- [ ] AC-5: a Bash command re-implementing a mapped affordance (per the act-to-affordance map) with no stated reason is flagged; a tool call is not (REQ-5).
- [ ] AC-6: a fan-out where ≥2 agents `cache_create` the same base-context bytes is flagged as cross-agent redundant load; a warm-handoff fan-out is not (REQ-6).
- [ ] AC-7: a dispatch with unspecified model or effort fails closed; a dispatch recording both proceeds (REQ-7).
- [ ] AC-8: a `limit=none` Read of a file over a declared size threshold is flagged; an offset/limit-scoped read of the same file is not (REQ-8).
- [ ] AC-9: the verifier computes `SHOULD` from the composition function's output and `WAS` from the transcript, and blocks on `WAS ⊉ SHOULD` (REQ-9).
- [ ] AC-10: a conformance figure sourced from an agent-authored record (not the harness transcript / CI-synced state) is rejected by construction (REQ-10).
- [ ] AC-11: the four canonical cost questions (is-100k-a-lot / makeup / cached / would-a-rewrite-reduce) are answered from the static bill + records with capture-source provenance on every figure; no OTel collector, dashboard, or dollar ledger is deployed (REQ-11).
- [ ] AC-12: a discipline delivered only as persona prose (no injection, no check) is flagged as non-control; an injected-or-checked one passes (REQ-12).
- [ ] AC-13: a review dispatch handed the author's rationale, or a curated summary in place of the raw artifact, is flagged; a warm-raw-slice-without-frame dispatch passes (REQ-13).
- [ ] AC-14: every efficiency-advisory figure carries a `recorded`/`measured`/`judgment` provenance tag; an untagged figure is rejected (REQ-14).
- [ ] AC-15: a design/review cycle whose declared composition (tracker) is not matched by its dispatch records (WAS ⊉ SHOULD) is flagged by the same verifier that governs build dispatches; a Red-Team pass over the cycle records no un-closed process bypass (REQ-15).

### Architecture

**Leverage crosslink; supply only the vsdd layer** (§355: crosslink's dispatch primitive "is strong on crosslink protocol and carries none of the vsdd layer"). 
- **Leverage (do not rebuild):** `swarm`/`kickoff` dispatch, worktrees, sessions (phase pointer in breadcrumbs §37), trust/signing, preflight (§108), and the viewers — mission control / tui / web dashboard (§149, "vsdd builds no viewer"; the efficiency insights surface there). The Claude Code transcript is the conformance oracle regardless of orchestrator.
- **Build/supply (the vsdd layer crosslink deliberately doesn't carry):** the **composition function** (Slice 2 — the SHOULD); the **injection seam** into the dispatch prompt (a named upstream capability requirement, §81, kickoff prompt-assembly the candidate); the **conformance verifier** (reads transcript WAS, compares to SHOULD, gates); the **efficiency insight engine** (reader over records, provenance-tagged). Verifier + engine home in `vsdd-core` (pure over the records) with a `vsdd`-binary command surface; they consume the same run records analyzed by hand this session (`agent-<id>.jsonl` usage/tool events; the journal).
- **The oracle + trust boundary (SA/RT):** the checked agent is untrusted with respect to its own conformance; evidence comes from the harness-produced transcript + CI over server-synced state (§264/#815). This is the hard-to-undo trust-boundary placement — the verifier must never read an agent-writable record as authoritative.
- **Delivery of injection while the upstream seam is unbuilt:** during bootstrap, injection is format-carried (the dispatch prompt assembles the required primer/domains/supplements from the composition) with the recorded Reads as the interim verification, until crosslink's kickoff prompt-assembly ships the seam (§81, #837).

### Out of Scope

- The telemetry apparatus — OTel collectors, sink wiring, dashboards, `vsdd observe`, the dollar ledger, calibration-tied-to-dollar-actuals (retired with `DESIGN-OBSERVABILITY.md`).
- A vsdd-built viewer (crosslink's mission control / tui / web dashboard are the surfaces, §149).
- A parallel orchestrator (ride crosslink `swarm`/`kickoff`; the `Workflow` tool is attended-fan-out affordance + bootstrap fallback only, not the target).
- Wall-clock-per-op and rate-limit-window SDK signals (a deferred optional complement; the transcript covers token/read/tool/cache — everything the conformance + read-inflation classes need).
- mdatron's config-integrity rules (cross-repo dependency, per Slice 2).
